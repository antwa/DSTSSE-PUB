# DSTSSE — Digimon Story: Time Stranger Save Editor

A desktop save editor for **Digimon Story: Time Stranger**. Edit your party, stats, inventory, field guide, and more — then keep your save safe.

> **This is the public release repository.** The source code is not available here. For bug reports and feature requests, use [Issues](../../issues).

## Downloads

Go to [**Releases**](../../releases) and download the latest zip for your platform:

| Platform | File | Notes |
|----------|------|-------|
| Windows x64 | `DSTSSE-v*-windows-x64.zip` | Portable — extract and run `dstsse.exe` |
| Linux x64 | `DSTSSE-v*-linux-x64.zip` | AppImage + .deb, works on SteamOS / most distros |

Each release includes `SHA256SUMS.txt` to verify your download.

## Requirements

- **Windows 10/11** — WebView2 (usually pre-installed)
- **Linux** — WebKit2GTK 4.1, libappindicator3

## Features

- Edit party Digimon (stats, skills, equipment, evolution)
- Edit inventory and items
- Browse field guide / DigiDex
- Backup and restore saves
- Custom icons per Digimon species
